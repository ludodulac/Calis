# Architecture de l'information

Cette architecture décrit la direction du site. Toutes les sections ne doivent pas être développées dès la V1.

## Navigation principale cible

### Apprendre
- Commencer de zéro
- Fondamentaux
- Exercices
- Figures
- Mobilité
- Récupération

### Progresser
- Parcours par objectif
- Progressions
- Programmes
- Tests de niveau
- Outils
- Journal de progression (futur)

### Comprendre
- Biomécanique
- Anatomie fonctionnelle
- Force et hypertrophie
- Volume, intensité et récupération
- Sensations et contrôle du mouvement
- Questions fréquentes approfondies

### S'équiper
- Guides d'achat
- Comparatifs
- Tests
- Catégories de matériel
- Boutique

### Pratiquer (futur)
- Parcs
- Clubs
- Coachs
- Associations
- Événements
- Compétitions

## Capacités

La bibliothèque peut également être parcourue par capacité :

- pousser ;
- tirer ;
- tenir ;
- s'équilibrer ;
- se mouvoir ;
- devenir plus fort.

## Exemples de hubs SEO

- Traction
- Dips
- Pompes
- Muscle-up
- Handstand
- Front lever
- Back lever
- Planche
- Human flag
- L-sit

Un hub n'est pas un simple article. Il rassemble le guide principal, les prérequis, la technique, les erreurs, les progressions, les régressions, les programmes, les questions associées et le matériel réellement pertinent.

## Modèle d'une fiche d'apprentissage

1. Capacité ou mouvement
2. Pourquoi l'apprendre
3. Prérequis
4. Test de départ
5. Technique
6. Ce que l'on doit ressentir
7. Signaux à ne pas ignorer
8. Erreurs fréquentes
9. Régressions
10. Progressions
11. Critères pour passer à l'étape suivante
12. Variantes
13. Matériel nécessaire / facultatif
14. Ressources liées
15. Sources et relecteurs éventuels

## Maillage

Chaque ressource doit pouvoir relier naturellement :

`question -> concept -> exercice -> progression -> programme -> équipement pertinent`

Le maillage doit d'abord aider le lecteur ; sa valeur SEO vient de cette structure cohérente.
