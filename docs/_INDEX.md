## Décisions et historique

Les fichiers `DECISION_*` décrivent une décision datée. Les fichiers `HISTORIQUE_*` servent à comprendre une évolution passée. **Ne pas les charger par défaut et ne pas les traiter comme état actuel.**

## Règle de travail

Avant d'optimiser une architecture ou un tunnel, distinguer :
1. ce que l'utilisateur veut réellement construire ;
2. ce qui est encore hypothèse (notamment orientation SEO/vente d'équipement) ;
3. ce que le code implémente déjà ;
4. ce qui mérite seulement une expérimentation.

Éviter de rendre irréversible une direction produit encore en réflexion.
